# Frontend Checklist

Every screen:

- loading state
- empty state
- success state
- error state
- permission state
- responsive layout
- accessible controls

Forms:

- client validation
- server validation handling
- disabled/submitting state
- success feedback
- actionable errors

Tables:

- pagination
- search/filter only where useful
- stable loading
- empty state
- row actions
- mobile strategy

Performance:

- no unnecessary client component
- no huge bundle import
- heavy libraries lazy-loaded
- avoid unnecessary refetches
