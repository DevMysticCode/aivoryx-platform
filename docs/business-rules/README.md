# Business rules

Captured business rules, per module, sourced from the client (see
`docs/owner/PRE-CODE-CHECKLIST.md`). Empty until Phase 2+.

Each rule is written so it can be turned into a test:

- **Rule:** what must always/never be true
- **Source:** who confirmed it, when
- **Applies to:** module / entity / state
- **Example:** concrete inputs → expected outcome
- **Open questions:** anything still ambiguous (do not guess — `TEAM-RULES.md` #10)
